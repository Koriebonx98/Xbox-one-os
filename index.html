🎮 Game OS

Console Experience for Windows

Game OS is a Windows C# & WPF App made to manage libraries such as games, apps, media and roms!


Game OS has a variety of features to make a Windows PC feel like a games console without "Steam Big Picture".


This project can be used to replace explorer.exe for a better experience but can also be run as it is.

✨ Features

  • Manage game libraries, apps, and media in one place
  • Console-like interface for Windows
  • Support for ROMs and emulation
  • Can replace explorer.exe for full console mode
  • Built with C# & WPF for native Windows performance
